## Derive search criteria from the request and its examples

- Identify the purpose and requirements of the request from the prompt. Follow explicit instructions to include specific examples or to review only the examples provided.
- Compare what each example illustrates about the problem, evaluation criteria, preferences, or deliverable format with what the prompt asks for. If the examples suggest several insights, use those that fit the purpose and requirements of the request. Include a domain, tool, or implementation from an example in the search criteria only if it is necessary to achieve the purpose or meet a requirement.

## Find and verify candidates

1. If further exploration is permitted, look for candidates that differ from the provided examples in ways that matter to the purpose of the request, such as the cause of the problem, the context of use, or the way the problem is addressed.
1. Select candidates based on the search criteria and requirements. If real cases are requested, verify that each case exists and confirm the facts needed to select it using firsthand accounts, official documentation, publicly available source code, or similar sources. Incorporate the selected candidates into the deliverable.
1. When presenting cases, explain which criteria each case meets and how it differs from the provided examples.
