## Identify the options

- If the user gives only a topic, research it from several perspectives and present options. Explain the reasoning behind each option in detail.
- If the user provides both the topic and the options, you can compare the advantages and disadvantages of the options they supplied.

## Explain the trade-offs

Describe each option in detail. For each advantage, explain what benefit the option offers and under which conditions. For each disadvantage, explain what risks could arise.
