# 선택과 이어가기

의도한 경험을 논의하고 의미 있는 방향을 사용자와 비교한다. 일상적인 세부 사항은 근거나 잠정 기본값으로 정해 CSS 속성보다 성과를 중심으로 대화한다.

## 질문 필요 여부 판단

- **근거로 결정 가능:** 요구사항, 관례, 접근성 조건이나 검증된 규칙으로 선택을 정할 수 있다. 이유를 설명하고 진행한다.
- **기본값 선택 가능:** 차이가 성과에 미치는 영향이 적고 승인된 방향에 맞는다. 일관되고 되돌릴 수 있는 잠정 기본값을 고르고 적용 범위를 밝힌다.
- **결정 필요:** 대안에 따라 행동, 정보 우선순위, 밀도, 위험이나 시각 방향이 의미 있게 달라진다. 관찰할 수 있는 차이와 장단점을 보여 주고 범위를 정해 선택을 요청한다.

새 방향에서는 관례로 세부 사항을 정할 수 있어도 필수 테마 비교를 제시한다. 의도한 경험에 영향을 주는 시각적 차이를 묻는다. 구독 사업 모델이나 모호한 형용사만으로 선호를 추정하지 않는다. 의도가 충분히 설명됐으면 초기 설문은 필요하지 않다.

확정된 선호나 검증된 규칙과 충돌하면 양립하지 않는 조건을 설명하고 규칙 변경, 예외 승인, 선택 제한 또는 보류 중 무엇을 할지 묻는다. 해결될 때까지 기존 규칙을 유지한다.

## 현재 문맥에서 이어가기

제공한 결과나 대화가 주제와 대상에 맞는지 확인하고 그 다음 행동을 따른다. 짧은 답변은 식별할 수 있는 보류 질문 하나에만 연결한다. 모호하거나 질문이 없으면 빠진 질문, 주제나 후보만 묻는다. 외관 판단을 요청하기 전에 확인할 수 없는 시각 자료를 다시 확보한다.

## 선택 요청과 답변 해석

새 비교에는 중요한 방향, 시나리오에 미치는 영향, 시각 근거, 장단점과 정확한 질문을 제시한다. CSS 속성을 하나씩 묻지 않는다. 선택은 명시하거나 확인한 특징만 승인한다. 적용을 넓히기 전에 불분명한 범위를 확인한다.

테마 답변에서는 유지할 계층, 이미지, 밀도나 명시된 특징을 선택하지 않은 부분과 구분한다. 피드백을 적용할 디자인 조건으로 바꾼다. 한 영역을 좋아한다고 참고 사례 전체, 모든 화면이나 모든 상호작용이 승인되지는 않는다. 다음 변경은 서비스 화면의 문구가 아니라 대화에서 설명한다.

질문 전에 후보, 볼 수 있는 근거, 정확한 질문, 보류 차수와 다음 행동을 확인할 수 있게 유지한다. 구조화된 입력은 답변까지 질문을 보존하고 수락, 거절 또는 취소의 명시적 결과를 보고할 때만 사용한다. 그렇지 않으면 일반 답변에서 묻고 기다린다.

기록한 질문 안에서 답변을 해석한다.

- **수락:** 확인된 범위 안에서만 적용한다.
- **거절:** 제시한 선택지가 선택되지 않았다고 기록한다. 더 넓은 기피나 다른 방향을 추정하지 않는다.
- **취소 또는 무응답:** 질문과 차수를 보류 상태로 유지한다. 승인, 거절이나 완료 차수로 처리하지 않는다.

구조화된 질문이 결과 없이 사라지면 일반 답변에 후보와 정확한 질문을 다시 제시한다. 잠깐 표시되는 패널만 유일한 기록이 되어서는 안 된다. 피드백을 해석하거나 다음 비교를 제시할 때 [차수 계산](#차수-계산과-탐색-종료)을 읽는다.

## XPath 수정 요청 해석

복사한 전체 XPath와 요청은 기존 시안의 수정 제안이며 새 테마 검색이 아니다. 현재 파일, 필요한 화면 상태, 확정 방향, 요청한 변경과 보존할 동작을 확인한다. 고정된 피드백 양식을 요구하지 말고 있는 문맥을 사용한다.

이전에 선택한 특징을 바꾸라는 명시적 요청은 그 변경을 허용한다. 같은 허용 여부를 다시 묻지 않는다. 의미, 대상이나 다른 확정 요구사항에 미치는 영향이 불분명하면 그 부분만 묻는다. 다른 유사 요소에 추정으로 적용하지 않는다. [대상 확인과 수정](implementation.md#복사한-전체-xpath로-수정)에 요청을 전달한다.

## 차수 계산과 탐색 종료

명시적으로 연장을 승인하지 않았으면 시각 주제별 최대 세 차수만 허용한다. 후보를 보여 주고 수락 또는 거절 피드백을 해석한 뒤에만 한 차수로 센다. 모든 후보를 거절하거나 결정할 수 없다고 명시해도 한 차수가 끝난다. 보류, 취소나 무응답 질문은 같은 차수로 남긴다. 제시 전의 내부 검색, 도구 호출과 접근 실패는 세지 않는다.

방향이 충분하면 일찍 멈춘다. 원칙 수를 고정하지 않는다. 확정 방향의 재개나 한정된 수정에서는 추가 차수가 없어도 된다. 이를 최초 테마 비교를 건너뛰는 데 쓰지 않는다.

세 차수 뒤에도 미해결이면 자동 검색을 멈추고 잠정 시각화, 추가 차수를 명시한 연장 또는 보류를 요청한다. 차수와 승인된 종료 지점을 보존한다. 연장 길이를 지어내거나 자동으로 다른 주제를 시작하지 않는다. 잠정 시각화에서도 미해결 선택은 열린 상태로 남는다.
