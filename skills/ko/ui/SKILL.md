# 서비스에 필요한 UI

서비스나 애플리케이션에 필요한 화면을 조사하고 화면별 UI 요소를 제안한다. 이미 제공할 수 있는 화면과 요소를 확인하고, 추가로 필요한 화면과 요소 및 표시 문구의 필요성을 검토한다. 화면에는 페이지, 스크린, 팝업 등 사용자에게 시각적으로 표시되는 인터페이스가 포함된다.

서비스 전반의 톤 앤 매너도 현재 적용 상태와 추가로 필요한 정보를 검토할 수 있다.

## 대상 서비스와 현재 상태 확인

- 프롬프트와 요구사항에서 제작 대상 서비스를 식별한다. 모노레포에 여러 서비스가 있으면 서비스별로 요구사항과 화면을 검토한다. 서로 다른 서비스를 하나의 검토 대상으로 통합하지 않는다.
- 프롬프트와 요구사항을 확인해 현재 제공할 수 있는 화면과 UI 요소, 추가 제작이나 수정이 필요한 화면과 UI 요소를 구분한다.
- 프롬프트나 요구사항이 갱신되면 대상 서비스의 화면과 UI 요소를 다시 확인한다.

## 필요한 화면 조사

사용자 유형별로 서비스가 제공해야 하는 기능과 UI, 서비스 이용 과정에서의 사용자 경험과 이용 시나리오를 확인한다. 이를 바탕으로 서비스마다 필요한 화면을 조사한다.

- 화면 후보를 도출하고 화면을 분리하거나 통합하는 기준 `<공란>`
- 조사 자료를 선택하고 화면 제안에 적용하는 기준 `<공란>`

## 화면별 UI 요소 구성

레이아웃과 패널부터 개별 UI 요소와 컴포넌트까지 조사한다. 다음 순서를 참고한다.

1. 화면에 필요한 레이아웃과 패널을 검토한다. 그리드나 리스트 등 화면에 정보를 배치하는 방식을 검토한다.
2. 레이아웃과 패널에 어떤 기능을 배치하고 어떻게 구분할지 검토한다.
3. 각 기능에 필요한 UI 요소를 식별하고 배치와 사용할 컴포넌트를 검토한다.
4. 이용 시나리오에 따라 UI 요소와 컴포넌트의 상태가 어떻게 바뀌어야 하는지 검토한다.

## 표시 문구의 필요성 검토

각 UI 요소에 레이블이나 안내 문구가 필요한지 조사한다. 필요한 문구를 제안하고 불필요한 안내 문구를 식별한다.

톤 앤 매너를 검토할 때는 서비스 전반에 현재 적용된 표현 방식을 확인하고, 설계 방향을 조사하며, 결정에 추가로 필요한 정보를 식별한다. 검토 대상은 다음과 같다.

- 색상과 전반적인 시각적 인상
- 글꼴과 텍스트 크기

서비스별로 필요한 화면과 화면별 UI 요소를 제안한다. 현재 제공할 수 있는 구성과 추가로 필요한 구성을 구분하고, 레이블이나 안내 문구의 필요성에 대한 판단을 제시한다. 톤 앤 매너를 검토한 경우 현재 적용 상태와 추가로 필요한 정보를 제시한다.
