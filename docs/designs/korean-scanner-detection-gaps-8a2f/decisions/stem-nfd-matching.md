# 어간 NFD 매칭과 허용 어미 집합 채택

## 결정이 필요한 이유

[요구사항](../requirements.md)은 네 가지 탐지 공백의 해소를 요구하면서 매칭 방식 선택을 미해결 질문으로 남겼다. [활용형 탐지 공백 재현과 공개 프로젝트의 어간 매칭 방식 조사](../references/stem-matching-research.md)가 선택지의 근거를 제공했고, 어느 구조를 채택할지는 결정 소유자의 판단으로 남아 있었다.

## 검토한 선택지

**표면형 열거 확장.** 매칭 엔진을 바꾸지 않고 활용형을 literal 표현으로 추가한다. 구현 변경이 가장 작지만 새 활용형마다 누락이 재발한다. [선행 결정](../../korean-scanner-coverage-9b4e/decisions/jamo-matching-and-close-rule.md)이 같은 이유로 열거 대신 자모 매칭을 채택한 바 있다.

**어간 중심 NFD 매칭.** 매칭 평면을 NFD로 통일하고 용언 규칙을 어간 단위로 등록하며, 자음 어미는 허용 어미 집합으로 검증한다. 네 공백을 한 구조로 해결하지만 규칙 스키마와 매칭 엔진의 변경이 가장 크다.

**실행 시점 표면형 생성.** 규칙은 어간과 어미 데이터로 두되 시작 시 표면형 literal을 생성해 현행 엔진으로 매칭한다. 엔진은 보존되지만 NFD로 저장된 원문은 별도의 입력 정규화로 처리해야 해 두 메커니즘이 남는다.

**형태소 분석기 도입.** 활용, 축약, 토큰 경계를 원리적으로 해결하지만, 외부 패키지 없이 실행하는 승인된 조건과 스크립트 복사 배포 방식을 깨므로 요구사항 변경이 선행되어야 한다.

## 승인된 결정

어간 중심 NFD 매칭을 채택한다. 결정 소유자가 다음 구성을 승인했다.

- 모든 표현을 NFD로 분해해 매칭 평면을 하나로 통일한다. NFD로 저장된 원문은 이 통일로 함께 잡는다.
- 용언 규칙은 어간을 표현으로 등록한다. 받침 없는 어간은 종성 자모 또는 어미가 이어지는지, 받침 어간은 다음 음절이 허용 어미 집합에 있는지 검증한다.
- 축약형과 불규칙 활용은 어간 변이형으로 규칙 데이터에 열거한다.
- 명사 규칙은 NFD 완전 일치로 두어 현재 literal 매칭과 같은 의미를 유지한다.
- 매칭 시작 위치는 음절 시작으로 제한하고, 경고의 위치와 인용은 기존 원본 offset 매핑 방식을 유지한다.

## 결정 이유

네 공백의 공통 원인은 검사 대상 개념이 어간인데 매칭 단위가 표면 문자열이라는 불일치다. 어간 중심 NFD 매칭은 이 원인을 승인된 실행 조건(외부 패키지 없음) 안에서 직접 제거하는 유일한 구조이고, 조사가 확인한 검증된 선례(hunspell-dict-ko의 NFD 내부 통일과 종성 자모 어미, Kiwi의 자모 시작 어미 항목)와 같은 원리다. 자모 매칭을 채택한 선행 결정의 연장선이라 결정 이력과도 정합한다. 자음 어미의 허용 어미 집합은 토큰화 없는 매칭에서 오탐을 막는 조사된 유일한 수단이며, 축약형 열거는 형태소 분석기를 쓰는 도구조차 피하지 못한 관행이다.

## 예상되는 영향

- `korean-expressions.mjs`의 규칙 스키마에 어간, 허용 어미 집합, 어간 변이형 개념이 추가되고 매칭 엔진이 NFD 단일 평면으로 재작성된다.
- 기존 `NFD_MATCHED_EXPRESSIONS` 허용 목록과 음절 literal 색인의 이중 구조는 제거된다.
- 받침 없는 음절로 끝나는 표현의 오탐 평가가 구현 전에 필요하다.
- 검사 결과의 JSON 구조는 [출력 구조 유지 결정](../../korean-scanner-coverage-9b4e/decisions/output-structure-and-alternative-search.md)에 따라 바뀌지 않으며, 경고 위치는 원본 UTF-16 offset 기준을 유지한다.
- 테스트는 기존 self-test의 확장이 아니라 사용자 시나리오 단위의 재구성이 필요하다. 방법은 별도 조사로 정한다.

## 다시 검토할 조건

- 허용 어미 집합에 없는 어미로 인한 누락이 실제 검토에서 반복 확인되면 집합의 관리 방식을 다시 검토한다.
- NFD 완전 일치로 전환한 명사 규칙이 대표 실행에서 무관한 합성어를 반복해서 잡으면 해당 규칙의 표현이나 경계 검증을 다시 검토한다.
- 어간 변이형 열거가 규칙 유지 부담을 실질적으로 키우면 표면형 생성 방식과의 절충을 다시 검토한다.
