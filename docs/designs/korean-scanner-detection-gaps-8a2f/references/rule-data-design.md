# 어간 규칙 자료 설계와 오탐 평가

## 조사 질문

[어간 NFD 매칭 결정](../decisions/stem-nfd-matching.md)이 승인한 구조를 `korean-expressions.mjs`의 규칙 자료로 옮길 때, 표현을 어떤 종류로 나누고 네 대상 규칙의 어간, 연결 목록과 변이형을 무엇으로 확정하며, 접두 매칭이 만들 수 있는 오탐을 어떻게 막는지 평가했다. [계획의 1번 작업](../plan.md)에 해당한다. 평가일은 2026년 8월 20일이다.

## 표현의 두 가지 매칭 종류

**완전 일치(exact).** NFD 평면에서 표현 자모열이 code point 경계에 정렬되어 시작하고 끝나는 일치다. 시작과 끝이 모두 정렬되므로 현재 literal 매칭과 같은 위치에서만 일치하고, 추가로 NFD로 저장된 원문도 잡는다. 명사와 구 표현 전체가 이 종류를 쓴다.

**어간 접두(stem).** 시작은 code point 경계에 정렬되고, 어간 자모열이 접두로 일치한 뒤 바로 뒤 문자를 연결 검증한다. 연결 검증은 다음 중 하나가 성립하면 통과한다.

- 뒤 문자가 종성 자모(U+11A8부터 U+11C2)다. 받침 없는 어간에 받침이 붙은 활용형(`다루` 뒤의 `ᆫ`)이 이 경우다.
- 뒤 자모열이 연결 목록의 항목 하나로 시작한다. 연결 목록 항목도 NFD 접두로 동작하므로 `으` 하나가 `은`, `을`, `음`, `으면`을 덮는다. 받침이 있는 어간(`박`)은 첫 조건이 자연 원문에서 발생하지 않으므로 사실상 이 조건만으로 검증된다.

어간 항목마다 두 가지 선택 속성을 둔다. **자유 연결**은 연결 검증을 생략하며, 어간 자체가 이미 활용된 변이형(`다뤄`)에 쓴다. 이는 결정이 승인한 어간 변이형 열거의 구체화다. **선행 경계**는 어간 바로 앞이 한글 음절이면 일치를 버린다. 이 속성은 승인된 결정에 없는 추가 검증이라 아래 오탐 평가의 제안 항목이며, 승인 전에는 규칙 자료에 쓰지 않는다. 경고의 위치와 인용은 어간 구간을 음절 끝으로 올린 원본 offset으로 보고한다.

다음 자모 관계를 Node.js 22에서 code point 수준으로 검증했다. `은`, `을`, `음`의 NFD는 모두 `으`의 NFD로 시작한다. `힌`, `힙`의 NFD는 `히`로, `혔`은 `혀`로, `았`은 `아`로 시작한다. `좁힌`에서 `좁` 뒤는 `히`로 시작하고, `박았`에서 `박` 뒤는 `아`로 시작하며, `다룬다`의 `다루` 뒤와 `회의를 가집니다`의 `회의를 가지` 뒤는 종성 자모다. 자유 연결 변이형 `다뤄`는 검증 대상이 아니지만, `다뤘다`에서 `다뤄` 뒤가 종성 자모라 음절 끝 올림으로 함께 잡히는 것도 확인했다.

## 공통 연결 목록

어미 연결 목록은 규칙별로 두지 않고 공통 상수 하나로 둔다.

> 다, 고, 게, 지, 는, 자, 며, 면, 니, 기, 네, 습, 아, 어, 으, 히, 혀

문법적으로 불가능한 조합(형용사 `좁` 뒤의 `자`)은 실제 원문에 나타나지 않으므로 목록을 공유해도 오탐을 만들지 않는다. 규칙별 예외가 실제 검토에서 확인되면 그때 규칙별 목록으로 나눈다.

## 네 규칙의 자료 구성

**`ko.narrow`.** 어간 `좁` 하나로 바꾸고 기존 NFD 표현 `좁히`, `좁혀`와 허용 목록 `NFD_MATCHED_EXPRESSIONS`를 제거한다. 선행 경계는 두지 않는다. `비좁다`는 같은 뜻 계열이라 잡는 것이 맞고, 저장소 말뭉치에서 `좁`을 포함한 어절은 전부 `좁다`와 `좁히다` 계열이었다. 연결 목록의 `히`가 사동 활용 전체(`좁힌`, `좁힐`, `좁힘`, `좁힙니다`)를, `혀`가 축약(`좁혔다`)을 덮는다. 형용사 용법을 포함하게 되므로 판정 질문의 보강 문안은 구현 작업에서 문구 검토와 함께 확정한다.

**`ko.fix-in-place`.** 어간 `박`은 승인된 연결 검증만으로는 오탐을 막지 못한다. 어미 `은`, `을`과 조사 `은`, `을`이 같은 글자라서 `압박을`, `반박은`, `도박을`처럼 `박`으로 끝나는 명사 뒤의 조사가 전부 연결 검증을 통과한다. 저장소 말뭉치에서도 한글 뒤에 `박`과 어미형 글자가 이어지는 사례(`수박고`)가 확인됐다. 평가자의 제안은 이 규칙에 선행 경계를 추가하는 것이며, 그 비용으로 `처박다`, `틀어박다`, 붙여 쓴 `못박다` 같은 합성 용언이 빠진다. 제안이 승인되기 전에는 어간 전환을 확정하지 않고 기존 다섯 literal을 유지한다.

**`ko.cover-topic`.** 어간 `다루`와 변이형 `다뤄`(자유 연결)로 바꾸고 사전형 literal `다루다`를 제거한다. 선행 경계는 두지 않는다. `다루`로 시작하는 다른 일반어가 확인되지 않았고, 말뭉치의 `다루다`, `다루는`, `다루지`, `다뤄야`가 모두 이 동사 계열이었다.

**`ko.hold-meeting`.** 어간 `회의를 가지`와 변이형 `회의를 가져`(자유 연결)로 바꾸고 사전형 literal `회의를 가지다`를 제거한다. 어간을 구 전체로 고정하는 이유는 말뭉치가 보여 준다. `가지` 단독은 수량 표현(`네 가지`, `가지를`, `가지로`)과 충돌하고, `가져` 단독은 다른 동사 `가져오다`(`가져올`, `가져온다`, `가져오지`)와 충돌한다. `데이터를 가져오다`의 NFD가 `회의를 가져`의 NFD를 포함하지 않음을 검증했다.

## 오탐 평가

**평가 대상 선정.** 완전 일치 표현은 시작과 끝이 모두 경계에 정렬되어 현재 literal과 같은 의미이므로 새 오탐이 생기지 않는다. 받침 없는 음절로 끝나는 표현 22개(`에 대해서`, `에 의해서`, `에 있어서`, `와의`, `하지 않으면 안 된다`, `범위`, `경계`, `경로`, `공개`, `포화`, `소유`, `표면화`, `견고`, `결과`, `데이터`와 용언 계열)를 분류로 확인했고, 이 가운데 접두 매칭으로 전환되는 것은 위 네 규칙의 용언 표현뿐이다. 따라서 오탐 평가는 어간 4개와 변이형 2개에 수행했다.

**항목별 결과.**

- `좁`: 말뭉치 근거로 오탐 없음. `좁쌀`은 `쌀`이 연결 목록에 없어 걸러진다.
- `박`: 승인된 연결 검증만으로는 조사 겹침 오탐이 남는다. 선행 경계를 켠 조건으로 다시 평가하면 남는 오탐 후보를 찾지 못했다.
- `다루`, `회의를 가지`, `다뤄`, `회의를 가져`: 위 규칙별 근거대로 충돌 후보가 없다.

`박`은 오탐이 결정의 매칭 구조만으로 해소되지 않는 경우라서 [계획](../plan.md)의 중단 조건에 해당한다. 결정 소유자가 선행 경계 제안을 판단하기 전에는 이 규칙의 구현을 시작하지 않는다. 나머지 어간과 변이형에서는 무관한 단어를 반복해서 잡는 표현이 발견되지 않았다.

## 규칙 자료 구조와 출력 유지

규칙 객체의 `expressions`는 완전 일치 문자열 배열로 유지하고, 용언 규칙에만 어간 항목 배열을 추가한다. 어간 항목은 어간 문자열, 선행 경계 여부와 자유 연결 여부를 가진다. `catalog`에는 완전 일치 표현과 어간 문자열을 합친 문자열 배열을 노출하고, 경고의 `expression`은 일치한 표현 또는 어간 문자열이다. 검사 결과의 JSON 구조는 [출력 구조 유지 결정](../../korean-scanner-coverage-9b4e/decisions/output-structure-and-alternative-search.md)대로 바뀌지 않는다. 규칙 검증은 어간 항목에도 기존과 같은 기준(비어 있지 않은 온전한 Unicode, quote 상한, 중복 금지)을 적용한다.

## 판단이 필요한 항목

- `ko.fix-in-place`에 선행 경계 검증을 추가할지는 결정 소유자의 판단이 필요하다. 승인된 결정에 없는 추가 메커니즘이며, 승인되지 않으면 이 규칙은 어간 전환 없이 활용형 열거 확장으로 되돌아간다.
- `처박다`, `틀어박다` 계열을 별도 어간으로 추가할지는 요구사항의 네 공백 밖이라 이 설계에 넣지 않았다. 같은 비유 계열이므로 추가할 가치가 있다는 것이 평가자의 제안이다.
- `ko.narrow`의 판정 질문 보강 문안은 구현 작업의 문구 검토에서 확정한다.

## 한계

- 말뭉치 평가는 이 저장소의 Markdown 파일에 한정했다. 다른 저장소의 글에서 새 충돌이 나타나면 [결정의 재검토 조건](../decisions/stem-nfd-matching.md)에 따라 다시 평가한다.
- 공통 연결 목록은 현재 네 규칙의 활용형에서 도출했고 한국어 어미 전수 조사가 아니다. 목록에 없는 어미(`던`, `려` 등)로 시작하는 활용형은 잡지 못하며, 실제 누락이 확인되면 목록에 추가한다.
- 선행 경계로 빠지는 합성 용언(`처박다` 류)은 위 판단 항목으로 남겼다.
