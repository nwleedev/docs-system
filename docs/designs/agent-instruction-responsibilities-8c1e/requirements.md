# 에이전트 지침의 책임 분리

## 목표

여러 저장소에 공통으로 적용할 작업 원칙은 유지하면서, 항상 읽히는 AGENTS.md와 필요할 때 읽는 Skill 및 저장소 문서가 같은 규칙을 중복해서 관리하지 않도록 책임을 나눈다.

## 유지할 전역 원칙

- 사실 판단이나 최신 정보가 필요한 요청에서는 인터넷 자료를 조사한다.
- 공식 문서, 표준, 원문과 공식 저장소 등 1차 자료를 최소 다섯 개 확보하려고 시도한다.
- 최종 답변에는 독자가 판단 근거를 확인할 수 있는 출처를 포함한다.
- 외부 의존성을 선택하거나 변경할 때에는 디자인 패턴을 조사한다.
- 파일 변경이 승인된 작업에서는 컨텍스트 압축 뒤에도 복구할 수 있도록 안전한 작업 단위의 커밋을 선호한다.
- Compound Engineering이 관리하는 Codex 도구 매핑 범위는 사용자가 직접 수정하지 않는다.
- Git 저장소의 변경 작업에는 워크트리, 작업 브랜치와 정해진 디렉터리 구성을 사용한다.

## 완료 조건

- 재사용할 외부 조사 결과와 저장소 근거가 설계 패키지에 기록되어 있다.
- 사용자가 확정한 전역 원칙과 그 영향을 결정 문서에서 확인할 수 있다.
- 작업이 끝난 뒤 사용할 AGENTS.md 전체와 변경하거나 추가할 Skills 및 docs의 본문 예시가 하나의 별도 Markdown 파일에 있다.
- 예시에는 최종 파일 구성, 파일별 본문, 그대로 유지할 파일과 변경할 구간이 구분되어 있다.
- 예시는 관리되는 Compound Engineering 범위를 수정 대상으로 제시하지 않는다.
- 이번 작업은 문서만 추가하고 실제 AGENTS.md, Skills와 설정 파일을 변경하지 않는다.
