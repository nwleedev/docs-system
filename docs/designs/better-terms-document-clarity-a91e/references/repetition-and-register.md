# 반복 표현과 보고서 문체의 판단 근거

문서 전체의 반복과 프로젝트별 문체를 따로 판단해야 한다. 빈도만 줄이거나 쉬운 동사를 격식 있는 동사로 일괄 교체하면 의미가 달라질 수 있다. 이 자료는 스킬 개선 설계자가 반복 탐지와 재작성 방식을 선택할 때 사용한다. 2026-11-02에 아래 원문을 확인했다.

## 외부 자료가 뒷받침하는 기준

[W3C의 간결한 텍스트 지침](https://www.w3.org/WAI/WCAG2/supplemental/patterns/o3p05-succinct-text/)은 “Have only one point per sentence.”라고 권고한다. 문장별 기능 분리를 뒷받침하지만 쉼표 개수나 한국어 문장 길이의 합격 기준을 제공하지는 않는다. WCAG 준수에 필수인 성공 기준이 아니라 보충 지침이다.

[Google의 국제 독자용 문서 지침](https://developers.google.com/style/translation)은 “Use consistent terminology”를 권고한다. 같은 개념을 가리키는 용어의 일관성은 보존해야 한다. 불필요한 반복을 줄이려는 요구를 모든 반복의 금지로 해석해서는 안 된다는 판단 근거다.

[WordPress의 단어 선택 지침](https://make.wordpress.org/docs/style-guide/language-grammar/word-choice/)은 독자에 맞는 용어 선택과 문맥 설명을 요구한다. [Google 문체 지침](https://developers.google.com/style/tone)은 친근한 대화체를 권장한다. 두 지침을 비교하면 쉬운 글과 보고서 문체는 동일한 규칙이 아니다. 외부 개발자 문서의 대화체 권고로 이 저장소의 보고서 문체 요구를 대체할 수 없다.

## 기존 기준과 남은 문제

[현재 스킬](../../../../skills/use-better-terms/SKILL.md)은 본문 전체와 목록 밖 표현을 검토하도록 정한다. [한국어 참고 자료](../../../../skills/use-better-terms/references/korean.md)는 필요한 용어 반복과 모호한 반복을 구분한다. 그러나 문서 전체의 동일 문형 반복과 프로젝트별 금지 표현 적용을 별도의 완료 근거로 요구하지 않는다. 지침의 존재만으로 이번 실패가 해결됐다고 판단할 수 없다.

[기존 요구사항](../requirements.md)은 새 빈도 집계를 구현 범위에서 제외했다. 이번 보완은 반복 방지라는 결과를 강화한다. 빈도 검사 재도입을 승인한 것으로 해석하지 않는다.

## 재작성 방식의 비교와 제안

고정 문형 탐지는 제시된 세 문형을 빠르게 발견할 수 있다. 다만 단어 순서가 달라진 표현이나 여러 절에 분산된 반복은 놓칠 수 있다. 문서 전체 검토는 이를 보완할 수 있지만 판단 편차가 남는다. 두 방식의 역할을 구분하는 방안을 제안하며 구체적인 구현은 미정이다.

보고서에서 `자료를 보았다`는 실제 행위가 열람이면 `자료를 열람했다`로 표현할 수 있다. 항목을 비교했다는 증거가 있을 때에만 비교 결과를 기술한다. `검증했다`라는 치환은 검증 방법과 결과가 확인된 경우에만 가능하다. 세 동사를 모든 문맥에서 금지할지에 대한 규칙은 아직 없다.

`A부터 B까지의 C`는 실제 범위인지 포괄성을 강조하는 수식인지 구분해야 한다. `A와 B를 C로 연결`은 참조 관계인지 자료 결합인지 확인해야 한다. `A,B,C 까지`는 단순 목록인지 추가 범위를 뜻하는지 확인해야 한다. 각 자리의 뜻이 확인되지 않으면 정해진 대체 문장을 적용할 수 없다.

프로젝트별 규칙은 기존 지침에서 먼저 확인하는 방안을 제안한다. 규칙이 없다는 이유로 금지 목록이나 설정 파일을 자동 생성할 필요는 없다. 저장 형식은 요구사항을 구현하는 단계에서 선택할 사항이다.

## 한계

영어 문서 지침은 한국어의 세 문형이나 세 동사가 항상 잘못됐다는 근거가 아니다. 이번 조사는 언어별 오류율이나 스킬 개선 효과를 측정하지 않았다. 현재 요구사항은 세 문형을 대표 사례로 취급한다. 실제 기간과 순서 및 구체적인 관계를 설명하는 사용은 보존한다. 고정 문형 탐지만으로 목록 밖의 상투적 서술을 방지할 수는 없다.
