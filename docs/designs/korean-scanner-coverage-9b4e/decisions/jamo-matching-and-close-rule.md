# 활용형 자모 매칭과 닫다 규칙 추가

## 결정이 필요한 이유

[한국어 스캐너 활용형 탐지와 대체 표현 제안 요구사항](../requirements.md)은 `좁힘`, `좁힐`처럼 받침이 붙어 음절이 달라진 활용형의 누락과 `닫다` 계열 규칙의 부재를 해결할 방향을 요구한다. [한글 활용형 탐지 방법 조사](../references/hangul-conjugation-detection.md)는 활용형 열거 확장과 NFD 자모열 접두 매칭을 비교했고, 어느 방식을 채택할지는 결정 소유자의 판단으로 남아 있었다.

## 검토한 선택지

활용형을 `expressions`에 열거하는 확장은 구현 변경이 없지만 새 활용형이 나타날 때마다 목록을 갱신해야 한다. NFD 자모열 접두 매칭은 갱신 부담이 없지만 원본 UTF-16 오프셋 매핑과 규칙별 오탐 평가가 필요하다. `닫다` 계열은 두 선택지와 무관하게 규칙 자체가 없어 추가가 필요하다.

## 승인된 결정

검사 스크립트에 자모 분해 매칭을 도입하고 `닫다` 계열 규칙을 추가한다. 결정 소유자는 이 두 항목을 구현 계획에 반영하도록 승인했다.

## 결정 이유

자모 매칭은 어간의 마지막 음절에 어떤 받침이 붙어도 같은 판정 기준의 후보를 찾으므로, 활용형이 나타날 때마다 목록을 고치는 방식보다 누락 재발 가능성이 낮다. `닫다` 규칙은 [닫다, 닫히다, 좁히다 용법 조사](../references/close-and-narrow-usage.md)가 정리한 판정 기준을 검토 후보로 연결한다.

## 예상되는 영향

`korean-expressions.mjs`의 탐색 방식과 규칙 목록이 바뀌고, self-test가 활용형 매칭과 오프셋 매핑을 검사하게 된다. 검사 결과의 JSON 구조는 [출력 구조 유지와 대체 표현 우선 탐색](./output-structure-and-alternative-search.md)에 따라 바뀌지 않는다. 구체적인 작업 단위와 검증은 [계획](../plan.md)이 정한다.

## 다시 검토할 조건

자모 접두 매칭이 대표 실행에서 무관한 단어를 반복해서 잡으면 해당 규칙의 매칭 방식과 표현을 다시 검토한다. 복합 받침으로 확장되는 활용형의 누락이 실제 검토에서 확인되면 종성 분해 테이블의 추가 여부를 검토한다.
