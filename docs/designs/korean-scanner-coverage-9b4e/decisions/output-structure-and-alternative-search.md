# 출력 구조 유지와 대체 표현 우선 탐색

## 결정이 필요한 이유

[한국어 스캐너 활용형 탐지와 대체 표현 제안 요구사항](../requirements.md)은 검사 스크립트가 후보를 알린 뒤 검토 단계에서 후보가 근거 없이 통과되는 문제의 개선을 요구한다. [검사 도구의 대체 표현 제안 방식 조사](../references/rewrite-suggestion-practices.md)는 규칙 자료에 대체 후보 필드를 추가하는 방향과 스킬 절차만 강화하는 방향을 비교했고, 채택은 결정 소유자의 판단으로 남아 있었다.

## 검토한 선택지

규칙 자료에 대체 후보 필드를 추가하면 검사 결과의 데이터 구조가 바뀌고 고정 후보가 문맥과 어긋나는 경우를 따로 걸러야 한다. 스킬 절차만 강화하면 스크립트와 출력 구조는 그대로 두고 검토자의 판정 행동을 바꾼다.

## 승인된 결정

검사 스크립트의 출력 데이터 구조는 그대로 유지한다. 대신 검토 절차를 강화해, 검토자는 경고된 표현마다 항상 다른 표현을 먼저 찾아보고 더 자연스러운 표현이 없다고 확인한 경우에만 원래 표현을 그대로 유지한다.

## 결정 이유

출력 구조를 유지하면 검사 결과를 소비하는 기존 절차와 자료가 바뀌지 않는다. 대체 표현 탐색을 판정의 기본 순서로 만들면, 경고를 그대로 통과시키는 판정에 탐색 결과라는 근거가 필요해져 잘못된 단어 사용이 검토를 그대로 지나가기 어려워진다.

## 예상되는 영향

`skills/use-words-review/SKILL.md`의 검토 기준과 `references/korean.md`의 판정 순서가 바뀐다. 경고가 자동 실패가 아니라는 기존 조건은 유지되며, 확립된 전문용어와 승인된 이름은 탐색 후 유지 근거로 기록할 수 있다. 구체적인 작업 단위와 검증은 [계획](../plan.md)이 정한다.

## 다시 검토할 조건

절차 강화 뒤에도 근거 없는 통과가 반복되는 사례가 확인되면 규칙 자료의 대체 후보 필드 추가를 다시 비교한다. 대체 표현 탐색이 확립된 용어까지 불필요하게 바꾸는 사례가 반복되면 유지 근거의 기록 방식을 다시 검토한다.
