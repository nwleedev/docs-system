# 닫다, 닫히다, 좁히다 용법 조사

## 조사 질문

`닫다`, `닫힘`이 실제 뜻과 무관하게 쓰여도 검사 스크립트가 후보로 찾지 못하는 문제와, `좁히다` 계열 경고를 판정할 때 유지할 용법과 고칠 용법을 나눌 근거를 조사했다. 이 조사는 [요구사항의 목표](../requirements.md#목표) 가운데 규칙 추가 방향에 해당한다. 조사일은 2026년 8월 20일이다.

## 사전이 정의하는 의미 갈래

`닫다`의 표준 의미는 물리적 개폐와 그 관용적 확장까지다.

- 열린 문짝, 뚜껑, 서랍 따위를 도로 제자리로 가게 하여 막다가 기본 의미다. [표준국어대사전의 닫다](https://stdict.korean.go.kr/search/searchResult.do?searchKeyword=닫다)가 이 뜻풀이를 제공한다.
- 회의나 모임을 끝내다, 하루의 영업을 마치다, 입을 굳게 다물다 갈래가 추가로 있다. [우리말샘의 닫다](https://opendict.korean.go.kr/search/searchResult?query=닫다)와 [한국어기초사전의 닫다](https://krdict.korean.go.kr/kor/dicMarinerSearch/search?mainSearchWord=닫다)가 같은 갈래를 확인해 준다.

`닫히다`는 문짝, 뚜껑, 서랍 따위가 도로 제자리로 가 막히는 피동이다. 사전상 피동의 주어는 물리적 대상이며, `닫음`과 `닫힘`은 별도 표제어가 아니라 명사형이다. [표준국어대사전의 닫히다](https://stdict.korean.go.kr/search/searchResult.do?searchKeyword=닫히다)를 확인했다.

`좁히다`는 세 갈래로 나뉜다. 면이나 바닥의 면적을 작게 하다, 너비나 거리를 작게 하다, 내용이나 범위를 작게 하다이다. [표준국어대사전의 좁히다](https://stdict.korean.go.kr/search/searchResult.do?searchKeyword=좁히다)와 [우리말샘의 좁히다](https://opendict.korean.go.kr/search/searchResult?query=좁히다)를 확인했다.

## 소프트웨어 문서에서 확립된 용법

UI 대상과 결합한 `닫다`, `닫기`는 공식 현지화 근거가 있다.

- Microsoft 한국어 스타일 가이드는 UI의 Close를 일관되게 `닫기`로 옮기고, 처음부터 한국어로 쓴 듯한 관용적 문장을 요구한다. [Microsoft Korean Style Guide](https://download.microsoft.com/download/5/b/6/5b62389f-4e3b-4c77-bc18-94efba2fa7bb/kor-kor-StyleGuide.pdf)에서 확인했다.
- GitHub 공식 한국어 문서는 같은 페이지에서 `이슈 닫기`와 `이슈 종결`을 뒤섞어 쓴다. `이슈 닫기`라는 명칭이 실제로 쓰인다는 근거는 되지만, 용어가 비일관적이어서 문장 수준 표현의 모범 근거로 쓰기는 어렵다. [GitHub Docs의 Closing an issue 한국어판](https://docs.github.com/ko/issues/tracking-your-work-with-issues/administering-issues/closing-an-issue)에서 확인했다.

## 판정 기준 분석

다음은 사전 갈래와 현지화 근거를 비교해 도출한 분석이며 승인된 결정이 아니다.

`닫다` 계열은 목적어나 주어가 무엇인지에 따라 갈린다. 창, 탭, 파일, 대화 상자처럼 개폐의 은유가 유지되는 UI 대상과 결합하면 확립된 용법이다. 반면 작업, 검토, 질문 같은 상태나 절차를 목적어나 주어로 삼는 문장은 사전의 어느 갈래에도 대응하지 않으며, 영어 close의 직역으로 보는 편이 근거에 맞다. 이런 문장은 작업을 완료로 처리한다, 질문을 마감한다, 검토를 끝낸다처럼 실제 행위를 적을 수 있는지 확인해야 한다.

`좁히다`는 세 갈래 모두 무엇을 줄이는지와 줄이기 전후의 기준을 전제한다. 좁히는 대상이 면적, 거리, 범위 가운데 무엇인지 드러나고 전후 기준이 문맥에 있으면 사전 용법이고, 대상이나 기준 없이 논의를 좁힌다, 문제를 좁힌다처럼 쓰면 무엇이 줄었는지 검증할 수 없는 용법이다. 이 기준은 현재 `ko.narrow` 규칙의 판정 질문과 방향이 같으며, 사전 갈래가 그 질문의 근거를 보강한다.

## 규칙 추가 방향

`닫다` 계열의 미탐지는 매칭 방식의 한계가 아니라 규칙 부재의 문제다. 어간 받침 ㄷ이 첫 음절 `닫`에 유지되어 `닫다`, `닫힘`, `닫힌`, `닫혔다`, `닫는다`가 모두 음절 `닫`을 그대로 포함하므로, literal 표현 `닫` 하나로 현재 음절 매칭이 이 활용형들을 모두 찾을 수 있다. 이 포함 관계는 Node.js에서 문자열 비교로 확인했고, 검사 스크립트에 규칙을 추가해 실행하지는 않았다. 따라서 새 규칙은 위 판정 기준을 담은 질문과 문제 사례 및 정상 사례를 갖추면 되고, 자모 매칭 채택 여부와 독립적으로 추가할 수 있다. 문제 사례와 정상 사례의 문안은 기존 규칙처럼 실패 구조만 남긴 합성 문장으로 작성하며, 확정 문안은 구현 변경에서 검토한다.

## 한계

- 작업을 닫힘으로 처리한다 같은 표현이 번역투라는 국립국어원의 직접 판정 자료는 확인하지 못했다. 위 분석은 그런 표현이 사전 의미 갈래와 일치하지 않는다는 점에서 도출한 추론이다.
- Google과 Apple의 공개 한국어 현지화 지침에서 close 항목은 1차 자료를 찾지 못했다.
- 격차를 좁히다, 간격을 좁히다가 사전 예문으로 실려 있는지는 뜻풀이 갈래로만 확인했고 원문 용례 화면은 확인하지 못했다.
