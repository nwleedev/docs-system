# 요구사항 최소 작성을 기본으로 적용

요구사항 생성과 보완은 입력에 근거한 최소 작성을 기본으로 한다. [요구사항](../requirements.md)의 「기존 문서 활용」과 「내용 작성과 구조 정리」에 적용하는 확정된 결정이다.

## 선택 이유와 영향

빈 문서 준비를 기본으로 두면 목표와 조건이 이미 입력되어 있어도 내용을 기록하려면 별도의 작성 단계가 필요하다. 최소 작성을 기본으로 두면 직접 파일을 편집할 수 없는 상황에서도 입력을 요구사항으로 정리할 수 있다. 따라서 빈 문서 준비를 기본으로 하는 방식 대신 입력을 최소한으로 정리하는 방식을 선택한다.

이 선택은 원문 복사, 임의의 기능 추가나 기존 문서 전체 대체를 허용하지 않는다. 빈 파일만 필요한 요청과 읽기 전용 검토도 내용 작성으로 바꾸지 않는다. 상세 작성 여부는 기본 작성 여부와 별도로 판단한다.

[계획](../plan.md)의 문서 작성 규칙과 기존 문서 탐색 절차에 반영한다. 생성 스크립트는 빈 파일 준비만 담당하므로 본문 생성 기능을 추가하지 않는다. 반복 요청에서 중복 내용이 추가되거나 빈 문서 요청에서 본문이 작성되면 요청 해석과 보완 절차를 다시 검토한다.
