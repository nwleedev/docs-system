# 한국어 채팅과 저장 결과물의 검토 구분

## 결정이 필요한 이유

[한국어 문서 검토 재발 방지 요구사항](../requirements.md)은 채팅과 한국어 문서에 같은 표현 기준을 적용하면서도, 일반 채팅에서는 `use-words-review`를 실행하지 않도록 요구한다. 기존 [채팅 답변의 한국어 품질 적용 조사](../references/conversational-korean-output-research.md)는 영향이 큰 답변에 독립 검토를 적용하는 방안을 권했다. 현재 스킬 절차는 독립 검토마다 초안 작성, 서브에이전트 호출과 결과 대조를 추가하지만, 중간 진행 알림을 전송 전에 가로채는 실행 지점은 정의하지 않는다.

OpenAI는 Codex가 작업을 시작하기 전에 AGENTS 문서를 읽는다고 설명한다. 스킬은 이름과 설명을 바탕으로 선택된 뒤 본문과 참고 자료를 읽으므로, 모든 채팅에 필요한 짧은 작성 규칙은 AGENTS에 두고 저장 결과물의 상세 검토만 스킬에 맡길 수 있다.

- [OpenAI의 AGENTS.md 안내](https://learn.chatgpt.com/docs/agent-configuration/agents-md)는 프로젝트 지침이 작업 시작 시 결합된다고 설명한다.
- [OpenAI의 스킬 작성 안내](https://learn.chatgpt.com/docs/build-skills)는 필요한 작업에서 스킬 본문과 자료를 불러오는 구성을 설명한다.
- [OpenAI의 지연 최적화 안내](https://developers.openai.com/api/docs/guides/latency-optimization)는 요청 횟수를 줄이면 왕복 지연도 줄어든다고 설명한다.

## 검토한 선택지

### 모든 한국어 채팅을 독립 검토하는 방법

최종 답변의 표현을 별도 관점에서 검사할 수 있다. 그러나 진행 알림까지 검토하려면 메시지마다 추가 호출과 결과 대조가 필요하고, 별도 검토자를 사용할 수 없는 환경에서는 같은 절차를 실행할 수 없다.

### 영향이 큰 최종 답변만 독립 검토하는 방법

호출 횟수는 줄지만 어떤 답변이 영향이 큰지 먼저 분류해야 한다. 중간 진행 알림에는 적용되지 않으며, 조사와 설명 답변이 반복될 때 지연이 계속 발생한다.

### 채팅 작성 규칙과 저장 결과물 검토를 분리하는 방법

일반 채팅은 AGENTS의 짧은 규칙을 생성할 때부터 적용한다. 한국어 문서와 저장, 커밋, 게시 또는 전달할 문구는 완성된 공유 단위로 묶어 `use-words-review`로 검토한다. 사용자가 특정 채팅 문구의 검토를 명시적으로 요청하면 문구 검토 자체가 결과물이므로 예외로 스킬을 실행한다.

## 승인된 결정

일반 채팅, 진행 알림과 설명 답변에는 `use-words-review`를 실행하지 않는다. 중간 메시지와 최종 답변은 두 배포용 AGENTS 문서에 직접 적은 한국어 작성 규칙을 따라 처음부터 작성한다.

`use-words-review`는 AI가 만들거나 고친 한국어 문서와 저장, 커밋, 게시 또는 전달할 한국어 문구를 검토한다. 채팅에서 만든 초안을 그대로 저장하거나 외부에 전달할 예정이라면 저장 결과물로 분류하고, 실제 저장 또는 전달 전에 한 번 검토한다.

사용자가 채팅에서 특정 문구의 검토를 명시적으로 요청하면 일반 채팅의 예외로 `use-words-review`를 실행한다.

## 예상되는 영향

두 배포용 AGENTS 문서는 채팅을 위한 짧은 작성 규칙과 저장 결과물의 스킬 실행 조건을 별도 항목으로 구분해야 한다. 일반 채팅 때문에 `references/korean.md`를 읽거나 서브에이전트를 호출하라는 지침은 제거한다. 저장 결과물을 검토할 때 literal 후보와 긴 문단 후보의 설명, 판정 질문과 대조 사례는 `scan-korean-expressions.mjs`가 제공하고, `korean.md`는 경고만으로 확정할 수 없는 문장과 문단의 의미 검토 기준을 맡는다.

`use-words-review`의 설명, 적용 범위, 주 에이전트 대체 절차와 보고 절차에서는 영향이 큰 사용자 답변을 자동 검토하는 조건을 제거한다. 명시적인 문구 검토 요청과 저장 예정 결과물은 계속 지원한다.

평가에서는 문장 품질과 스킬 호출 범위를 따로 확인한다. 일반 채팅과 진행 알림에서는 스킬 호출이 없어야 하고, 한국어 문서와 명시적인 문구 검토 요청에서는 한 번의 검토가 실행되어야 한다.

AGENTS 지침은 생성되는 문장에 영향을 줄 수 있지만 전송 직전 검사를 강제하지 않는다. 따라서 이 결정은 모든 채팅 문장이 규칙을 지킨다고 보장하지 않으며, 대표 대화의 실제 출력으로 계속 확인해야 한다.

## 다시 검토할 조건

채팅 제품이 전송 전 문장을 별도 지연 없이 검사하는 실행 지점을 제공하거나, AGENTS 규칙만 적용한 대표 평가에서 같은 결함이 반복되면 채팅 검토 방법을 다시 비교한다. 일반 채팅과 저장 결과물의 구분이 반복해서 다르게 해석되면 스킬 설명과 평가 사례를 먼저 보완한다.
