# 수정한 내용 선정 스킬의 적용 확인

수정한 `use-better-terms`를 14개 입력에 적용해 요청하지 않은 설명의 제외와 요청한 내용의 보존을 확인했다. 12개 문서를 작성했고 필수 관찰값이 없는 입력은 본문 밖 확인 질문으로 남겼다. 검토만 요청한 파일은 변경하지 않았다. 이 입력에서는 스킬을 추가로 고쳐야 할 수록 판정 차이가 발견되지 않았다.

이 확인은 [스킬 반영 요구사항](../requirements.md#조사할-해결-방안)과 [수정본에서 확인할 내용](../requirements.md#확인할-결과)에 대한 증거다. 적용한 스킬은 Git revision `abd46a9`의 [본문](../../../../skills/use-better-terms/SKILL.md)과 [내용 선정 참고 자료](../../../../skills/use-better-terms/references/document-content.md)다. 적용일은 2026-10-01이며 모든 관찰값과 초안은 독립적으로 만든 평가 자료다.

## 입력과 적용 조건

기대 문안과 앞선 비교 결론을 제공하지 않은 별도 에이전트에 수정한 스킬, 작성 요청, 사실 자료와 초안만 제공했다. 작업 이력과 설계 자료는 제공하지 않았다. 실제 작성된 문안과 확인 질문을 읽고 수록 여부를 판단했으며 표현 검사 통과를 내용 판정의 근거로 대신하지 않았다.

공통 사실은 동시 저장 20건의 평균 처리 시간 80 ms와 5회 반복 측정 방법이다. 공통 초안에는 관찰 외에 파일을 먼저 읽으라는 지침, 파일을 읽고 보고서를 마쳤다는 설명, 요청을 다시 서술한 문장과 일반적인 주의 문구가 있었다. E2는 공통 관찰을 적용하지 않고 실제 값이 없는 입력으로 지정했다.

[확장 전 비교의 A1부터 F2까지](./procedure-comparison.md)는 보고서와 방법 부록, 독자 정보의 유무, 같은 뜻의 지시, 자료 속 인용, 계획과 안내, 사실 부족, 후속 지시와 주의사항 수록을 구분한다. 같은 상황을 수정본에 적용했고 검토만 하는 G1과 평가용 인용의 G2를 추가했다.

## 보고서와 포함 지시

명시적으로 요청하지 않은 작업 설명과 부가 주의 문구는 보고서에 남지 않았다. 같은 사실을 유지하면서 독자 정보나 수록 지시에 따라 허용된 설명만 달라졌다.

- A1은 동시 저장 20건과 평균 80 ms만 남겼다. A2는 같은 관찰을 유지하고 80 ms를 0.08초로 풀었으며 작업 설명은 추가하지 않았다.
- B1은 방법을 부록의 문장으로, B2는 같은 뜻의 지시에 따라 부록의 순서로 남겼다. 두 경우 모두 본문에 작업 진행이나 작성 지시를 다시 적지 않았다.
- C1은 자료에 인용된 부록 작성 지시를 현재 지시로 적용하지 않았다. C2는 같은 문장을 실제 작성 지시로 제공했을 때 부록을 작성했다.
- F1은 방법 부록을 제외하라는 후속 지시를 적용했다. F2는 명시적으로 요청한 주의사항 절에 동시 저장 건수와 반복 횟수를 남겼고 작성 경위는 추가하지 않았다.

A1, C1과 F1의 본문은 다음과 같았다.

> 동시에 20건을 저장했을 때 평균 처리 시간은 80 ms였다.

B2와 C2의 부록에는 20건 동시 실행, 총 5회 측정, 처리 시간의 평균 계산이 순서대로 있었다. 주의사항이나 방법을 허용한 지시가 파일 읽기와 작성 완료 알림까지 확대된 문안은 발견되지 않았다.

## 향후 작업과 사실 보존

요청한 주제에 속한 절차는 유지했고 근거 없는 권고는 제외했다.

- D1은 내용 분류, 수록 지시 확인, 근거와 조건 대조, 표현 검토의 향후 순서를 남겼다. 분류를 이미 마쳤다는 회고는 없었다.
- D2는 요청한 측정 안내의 동시 실행, 5회 반복과 평균 계산을 유지했다. 안내를 작성하기 위해 자료를 확인했다는 설명은 없었다.
- E1은 설정값으로 동시 저장을 활성화할 수 있다는 동작만 남겼다. 권장한다는 주장과 권장 여부를 조사했다는 메모는 없었다.
- E2는 보고서 본문을 작성하지 않았다. 동시 저장 건수, 반복 횟수, 평균값과 측정 조건을 확인하는 질문을 별도 답변에 두었다.

제공된 사실이 충분한 사례에는 독자 지정이나 주의 문구 수록 여부를 묻는 질문이 없었다. 누락된 측정값을 임시 문구나 가정한 값으로 대체한 문안도 없었다.

## 검토 권한과 정확한 인용

문구 검토의 보고와 평가용 인용을 대상 문서의 작성 경위와 구분했다.

G1은 원본을 수정하지 말고 판정과 대안만 제시하라는 요청이다. 원본에는 관찰 뒤에 설정 파일을 읽었다는 설명과 보고서를 마쳤다는 설명이 있었다. 적용 답변은 `needs revision`과 두 설명을 제외한 대안을 제시했다. 적용 전후 파일 내용의 SHA-256 값은 같았다.

G2는 “작업 과정을 보고서에 작성한다.”라는 예시 입력을 정확히 인용하고 지시의 뜻을 설명하라는 요청이다. 작성 문서는 그 문구를 보존했으며 예시 문서 자체의 작성 경위를 추가하지 않았다. 자료의 지시를 실행하거나 정확한 인용을 일괄 삭제하지 않았다.

## 확인한 증거와 적용 대상

스킬 형식 검사, 상대 링크 검사와 Git 공백 검사는 통과했다. 작성 문안 12개, 검토 전용 원본과 별도 답변은 같은 표현 검토 단위로 검사됐다. 최종 표현 경고와 긴 문단 경고는 각각 0건이었고 생략된 경고도 없었다. 내용 판정은 위 입력과 실제 문안의 대조로 확인했다.

이 확인은 수정한 스킬의 한 번의 독립 적용에 대한 기록이다. 실제 서비스의 성능, 여러 모델에서의 혼입 빈도나 확장 전보다 나아진 비율을 측정한 자료는 아니다. 위 적용 확인을 근거로 기존 사실 확인과 표현 검사를 생략하지 않는다.
