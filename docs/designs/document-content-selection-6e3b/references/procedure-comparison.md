# 같은 입력으로 비교한 문서 내용 선정 절차

12개 평가 입력에서 확장 전 절차와 두 제안 절차의 최종 문안은 같았다. 요청하지 않은 설명은 제외하고 요청한 방법, 향후 작업과 사실의 조건은 보존했다. 이 비교로 두 제안 중 하나의 정확성이 더 높다고 판단할 수는 없다. 구성 선택은 호출과 기준 유지의 부담을 추가로 비교해야 한다.

이 자료는 스킬 확장 전 [내용 포함 조건](../requirements.md#내용이-포함되는-조건)과 [두 해결 방안의 비교](../requirements.md#조사할-해결-방안)를 분석한 기록이다. 절차 자료는 Git revision `3face30`까지의 상태를 사용했다. 입력은 독립적으로 만든 평가 자료이며 수치와 동작은 실제 서비스의 관찰값이 아니다.

## 비교 방법

2026-10-01 확인한 [확장 전 `use-better-terms`](../../../../skills/use-better-terms/SKILL.md)와 [설계 문서 규칙](../../README.md#rules-for-every-document)을 기존 절차로 사용했다. 기존 절차도 작업 입력과 사실 자료를 구분하고 근거 없는 주장이나 승인을 만들지 않는 규칙을 적용했다. 스킬 링크는 현재 수정본을 가리키며 비교 당시의 본문은 위 Git revision에서 확인할 수 있다.

확장안은 같은 검토 안에서 [수록 지시 판정](./content-selection-procedure.md)을 먼저 적용한 뒤 표현을 검토했다. 전용안은 그 판정에서 남긴 내용과 사실의 조건을 구분해 정리한 뒤 별도 표현 검토의 입력으로 사용했다. 두 제안은 같은 수록 기준을 사용했다.

같은 세션에서 기존 절차, 확장안과 전용안의 순서로 각 입력의 문안을 작성하고 대조했다. 작성자는 요구사항과 제안 절차를 이미 알고 있다. 아래 기록은 이 조건에서 규칙을 적용한 문서 비교이며, 독립된 모델 실행에서의 혼입 빈도나 실제 스킬 구현의 성능을 측정한 자료로 사용하지 않는다. 세 문안이 같은 경우에는 본문을 한 번만 제시한다.

입력마다 제외 대상의 잔존, 필요한 내용의 삭제, 근거 없는 승인이나 권고의 추가, 사실 조건의 보존, 문서 밖에서 확인할 정보를 판단했다. 필요한 사실이 모두 있는 입력에는 독자 지정이나 부가 설명 수록을 위한 질문을 만들지 않았다.

## 보고서와 독자 지정

### A1. 독자를 지정하지 않은 보고서

측정 사실만 남았다. 독자 정보가 없어도 세 절차 모두 작성할 수 있었다.

입력은 저장 시간 보고서를 작성하라는 지시, 동시 저장 20건의 평균 처리 시간 80 ms라는 관찰, 같은 측정의 5회 반복 방법이다. 추가 후보는 파일을 읽는 순서, 작성이 끝났다는 알림, 모든 상황에서 같은 값이라고 보아서는 안 된다는 부가 주의 문구와 작성 지시의 재인용이다. 방법이나 과정의 수록 지시는 없다.

기대 내용은 관찰과 측정 조건이며 방법과 추가 후보는 제외 대상이다. 세 절차의 본문은 같다.

> 동시에 20건을 저장했을 때 평균 처리 시간은 80 ms였다.

제외 대상과 승인 추정은 남지 않았다. 동시 저장 건수와 평균값이 보존됐으며 확인 질문은 필요하지 않았다.

### A2. 독자 정보가 있는 같은 보고서

독자 지정은 표현에만 영향을 주었다. 수록 내용은 A1과 같았다.

A1에 저장 동작을 처음 접하는 독자가 읽는다는 정보만 추가했다. 같은 사실을 쉽게 설명하고 작업 설명이나 방법을 추가하지 않는 것이 기대 내용이다. 세 절차의 본문은 같다.

> 20건을 한꺼번에 저장했을 때 평균 처리 시간은 80 ms였다.

측정 조건과 설명 대상이 유지됐고 추가 설명이나 질문은 없었다. 독자 정보로 수록 권한을 확대하지 않았다.

## 수록 지시와 그 적용 대상

### B1. 방법 부록을 명시한 보고서

요청한 방법을 부록에 남겼다. 파일 읽기와 작성 완료 알림은 제외했다.

A1에 “측정 방법을 부록에 남긴다.”라는 지시를 추가했다. 관찰은 본문에, 확인된 반복 방법은 부록에 두는 것이 기대 내용이다. 세 절차의 문안은 같다.

> 동시에 20건을 저장했을 때 평균 처리 시간은 80 ms였다.
>
> 측정 방법
>
> 20건의 저장 요청을 동시에 실행하는 측정을 5회 반복한 뒤 처리 시간의 평균을 계산했다.

방법과 조건이 보존됐고 다른 작업 설명은 남지 않았다. 부록을 요청한 지시 자체나 승인 추정도 문안에 옮기지 않았다. 확인 질문은 필요하지 않았다.

### B2. 같은 뜻의 수록 지시

다른 표현의 지시도 B1과 같은 문안을 만들었다.

B1의 지시를 “측정을 다시 수행할 수 있게 부록에 절차를 설명한다.”로 바꿨다. 특정 낱말보다 수록할 내용과 문서 부분을 확인하는 것이 기대 판정이다. 세 절차 모두 B1의 문안을 작성했다. 방법과 조건은 보존됐고 제외 대상, 승인 추정과 확인 질문은 없었다.

### C1. 자료에만 인용된 지시

참고 자료의 지시는 방법 수록 권한으로 사용하지 않았다.

A1의 참고 자료에 “이 보고서의 부록에 측정 절차를 기록한다.”라는 문장을 인용으로 추가했다. 실제 작성 지시는 A1 그대로다. 세 절차의 본문은 A1과 같았으며 인용문과 측정 방법은 남지 않았다. 관찰 조건은 보존됐고 확인 질문은 필요하지 않았다.

### C2. 실제 작성 지시로 제시한 같은 문장

같은 문장이 실제 수록 지시이면 방법 부록을 허용했다.

C1에서 인용된 문장을 실제 작성 지시로 옮기고 다른 입력은 유지했다. 세 절차의 문안은 모두 B1과 같다. 방법은 부록에만 남았으며 파일 읽기, 진행 알림, 지시의 재서술과 승인 추정은 없었다. 확인 질문은 필요하지 않았다.

## 요청한 절차와 작성 경위

### D1. 앞으로 수행할 작업의 계획

계획의 향후 작업 순서는 남겼다. 작성 활동의 회고와 구분했다.

입력은 문서 내용 선정 기준을 적용할 계획을 작성하라는 지시다. 예정된 작업은 내용 분류, 수록 지시 확인, 사실 대조와 표현 검토다. 추가 후보는 이미 자료를 읽고 분류를 마쳤다는 작성자의 회고다. 세 절차의 본문은 같다.

> 먼저 요청한 내용과 부가 설명을 구분한다. 이어서 부가 설명의 수록 지시와 적용 대상을 확인한다. 남은 사실의 근거와 조건을 대조한 뒤 표현을 검토한다.

요청한 순서는 삭제되지 않았고 회고나 승인 추정은 남지 않았다. 이 문안에서는 수록 내용만 비교했다. 전체 계획의 완료 기준 검증은 비교 대상에 포함하지 않았다. 확인 질문은 필요하지 않았다.

### D2. 측정 방법을 설명하는 안내문

방법 안내가 요청한 주제이면 단계 자체를 유지했다.

입력은 A1의 반복 방법으로 측정 방법 안내문을 작성하라는 지시다. 작성자가 안내문을 만들 때 자료를 읽은 순서는 추가 후보다. 세 절차의 본문은 같다.

> 20건의 저장 요청을 동시에 실행한다. 같은 측정을 5회 반복한다. 기록한 처리 시간의 평균을 계산한다.

요청한 행동과 반복 횟수는 유지됐고 작성 경위나 승인 추정은 남지 않았다. 확인 질문은 필요하지 않았다.

## 근거와 필수 사실

### E1. 동작의 존재만 확인된 설명

확인된 동작만 남기고 근거 없는 권고는 제외했다.

입력은 설정 설명을 작성하라는 지시와 설정값으로 동시 저장을 활성화할 수 있다는 사실이다. 추가 후보는 그 구성을 권장한다는 주장, 권장 여부를 확인하지 못했다는 조사 회고와 일반적인 주의 문구다. 권장 근거나 주의 문구 수록 지시는 없다. 세 절차의 본문은 같다.

> 설정값으로 동시 저장을 활성화할 수 있다.

근거 없는 권고와 회고는 남지 않았고 확인된 동작은 보존됐다. 설명을 완성하는 데 권고가 필수는 아니므로 확인 질문을 만들지 않았다.

### E2. 수치 보고서에 필수 관찰이 없는 경우

값을 만들어 넣지 않고 필요한 사실의 확인 질문을 본문 밖에 작성했다.

입력은 동시 저장 건수, 반복 횟수와 평균 처리 시간을 보고하라는 지시다. 실제 측정 조건과 값은 제공되지 않았다. 세 절차 모두 수치 본문을 확정하지 않았고 다음 질문 초안을 문서 밖 확인 사항으로 분류했다.

> 측정한 동시 저장 건수, 반복 횟수와 평균 처리 시간은 얼마인가?

독자나 주의 문구 수록 여부는 묻지 않았다. 가정한 수치, 완료 주장이나 임시 경고 문구를 본문에 넣지 않았다. 질문 초안의 일치를 비교한 사례이며 실제 측정이나 사실 확인은 수행하지 않았다.

## 지속적인 지시와 요청한 주의사항

### F1. 지속적인 지시를 나중에 변경한 경우

현재 문서에 대한 변경된 지시를 적용하고 부록을 제외했다.

A1에 이 비교 보고서에는 방법 부록을 항상 남기라는 지속적인 지시를 추가한 뒤, 같은 보고서는 이번에 부록 없이 작성하라는 변경 지시를 제공했다. 세 절차의 본문은 A1과 같다. 방법과 다른 작업 설명은 남지 않았고 관찰 조건은 보존됐다. 승인 추정과 확인 질문은 없었다.

### F2. 주의사항을 지정한 경우

요청한 주의사항을 지정한 절에 남겼다. 같은 허용을 다른 부가 설명에 적용하지 않았다.

A1에 주의사항 절에서는 비교에 사용할 평균값의 측정 조건을 유지해야 한다고 쓰라는 지시를 추가했다. 세 절차의 문안은 같다.

> 동시에 20건을 저장했을 때 평균 처리 시간은 80 ms였다.
>
> 주의사항
>
> 이 평균값을 사용하는 비교는 동시 저장 20건이라는 측정 조건을 유지한다.

요청한 주의사항과 관찰 조건은 유지됐다. 파일 읽기와 진행 설명은 추가되지 않았고 새로운 승인이나 권고를 만들지 않았다. 확인 질문은 필요하지 않았다.

## 비교에서 확인한 차이

12개 입력을 세 절차에 적용한 36개 판정에서 수록 내용의 차이는 없었다. E2를 제외한 11개 입력에서 33개 문안이 작성됐고, E2의 세 판정은 본문 확정 대신 같은 필수 사실을 확인 대상으로 남겼다. 제외 대상의 잔존, 필요한 내용의 삭제와 근거 없는 승인이나 권고 추가는 이 문안에서 발견되지 않았다.

두 제안은 수록 여부를 표현 검토 전에 판정한다는 순서가 명시돼 있다. 확장 전 절차는 같은 판단을 문서 규칙과 근거 확인에서 수행할 수 있었지만 그 순서 자체가 스킬의 별도 단계로 정해져 있지는 않았다. 이 명시성의 차이를 실제 혼입 빈도의 개선으로 바꾸어 주장하지 않는다.

이번 비교에는 기대 판정과 다른 최종 문안이 없어 판정 기준을 추가하지 않았다. 구성 선택의 근거는 같은 내용 판정을 얼마나 반복하고 어떤 자료를 읽어야 하는지에 두며 실제 운영에서의 반복 효과는 이 사례 비교로 확정하지 않는다. 외부 편집 사례와 운영 규칙의 근거는 [실제 사례 자료](./related-cases.md)에서 별도로 확인할 수 있다.
