# 요청하지 않은 작업 설명을 제외하는 기준의 적용 계획

내용 분류, 수록 지시 판정, 기존 지침 대조, 12개 입력의 문안 비교와 스킬 구성 방안 비교를 마쳤다. 현재 저장 전 검토에 내용 선정을 추가하는 `use-better-terms` 확장안을 우선 권고한다. 실제 적용할 구성과 변경할 기준은 미결정이며 실제 스킬은 수정하지 않았다.

이 계획은 [요구사항의 내용이 포함되는 조건](./requirements.md#내용이-포함되는-조건), [조사할 해결 방안](./requirements.md#조사할-해결-방안), [계획에 담을 절차](./requirements.md#계획에-담을-절차)와 [확인할 결과](./requirements.md#확인할-결과)를 기준으로 한다. 실행 순서는 내용 분류, 포함 지시 판정, 기존 지침과의 조정, 비교 사례 평가, 스킬 구성 방안 비교다.

## 1. 제외할 설명과 요청한 내용을 구분한다

[분류 기준](./references/content-classification.md)에 작성 지침, 진행과 회고, 부가 주의 문구, 사실과 조건, 향후 절차, 요청한 방법과 평가 입력을 구분해 정리했다. 문장의 설명 대상과 요청한 내용을 기준으로 분류하며 단어만으로 삭제하지 않는다.

확인 근거는 각 유형의 포함 또는 제외 예시, 조건을 삭제했을 때 달라지는 주장, 실제 편집 안내와 검색 상황 사례의 연결이다. 같은 수행 절차라도 요청한 문서의 주제이면 유지하고 작성 활동의 회고이면 수록 지시를 확인한다. 2단계의 판정 절차는 이 분류를 사용한다.

## 2. 명시적 포함 지시를 판정하는 순서를 정한다

[판정 절차](./references/content-selection-procedure.md)에 수록 지시가 없으면 제외하고 지시한 문서와 내용만 허용하는 순서를 정리했다. 예상 독자 지정은 필수 입력으로 요구하지 않는다.

확인 근거는 일반 보고서 요청과 방법 부록 요청의 구분, 동일한 뜻의 지시 두 표현, 지속적인 지시의 적용과 변경, 자료 속 인용의 제외 사례다. 본문에 필요한 사실이 부족한 경우만 문서 밖에서 확인한다. 이 순서와 포함 조건을 3단계의 기존 지침 대조에 사용했다.

## 3. 사실 보존과 기존 지침을 함께 적용한다

[기존 지침 대조](./references/guidance-alignment.md)에 보완할 입력 조건과 보고 대상, 유지할 사실과 승인 규칙을 정리했다. 독자를 매번 질문하거나 작성 경위를 본문에 넣도록 요구하는 지침은 대조한 자료에서 확인되지 않았다.

확인 근거는 저장소 지침의 각 절과 연결된 적용안, 조건을 보존한 관찰 문장, 근거 없는 일반화와 승인 추정의 제외 기준이다. 실제 스킬과 저장소 공통 지침은 수정하지 않았다. 4단계의 문안 비교와 5단계의 구성 비교에 같은 적용안을 사용했다.

## 4. 같은 입력으로 판정 차이를 비교한다

[12개 입력의 비교](./references/procedure-comparison.md)에 입력, 기대 내용, 작성 문안과 사실 확인 항목을 정리했다. 보고서와 방법 부록, 독자 정보의 유무, 실제 지시와 자료 속 인용을 짝지었고 같은 뜻의 지시, 향후 작업과 사실 조건도 포함했다.

확인 근거는 세 절차에 적용한 36개 판정이다. 11개 입력의 33개 문안은 수록 내용이 같았고 필수 사실이 없는 입력은 본문을 확정하지 않고 같은 확인 질문을 남겼다. 제외 대상의 잔존, 필요한 내용의 삭제와 승인 추정은 발견되지 않았으며 독자 지정 질문도 필요하지 않았다. 기대 내용과 다른 최종 문안이 없어 판정 기준을 추가하지 않았다.

비교는 모든 기준을 아는 작성자가 같은 세션에서 적용한 문안에 한정한다. 실제 운영의 혼입 빈도나 두 제안의 정확성 우열을 확정하지 않는다.

## 5. 두 스킬 구성 방안을 비교한다

[구성 방안 비교](./references/skill-composition-comparison.md)에 같은 문서 묶음의 수록 판정과 표현 검토를 마치는 조건을 적용했다. 논리적 호출은 확장안 한 번, 전용안 두 번이다. 활성화할 절차 본문도 각각 하나와 두 개이며 내용 판정 기준은 두 방안 모두 한 묶음으로 유지할 수 있다. 실제 토큰과 도구 실행 횟수는 측정하지 않았다.

확인 근거는 현재 저장과 공유 규칙, 두 방안의 호출 순서, 필요한 자료와 판정 근거 전달 조건이다. 자료 수집은 확장안에서 한 번이며 전용안에서도 전달하면 한 번으로 유지할 수 있다. 현재 확인한 지침은 저장 전 표현 검토를 요구하며, 내용 판정만 별도로 완료해야 하는 반복 작업은 확인되지 않았다.

현재 호출 규칙에 맞고 별도 근거 전달 절차가 필요하지 않은 확장안을 우선 권고했다. 정확성 우열에 따른 권고는 아니다. 실제 구성 선택과 바꿀 기준은 미결정이며 독립 호출의 반복 필요가 확인되면 구성을 다시 비교한다.

## 후속 작업의 조건

이 계획의 범위는 문서 내용 판정과 적용 방안 비교다. 후속 비교를 추가하는 경우에도 예상 독자를 지정하지 않았다는 이유로 중단하지 않는다.

- 본문에 필요한 사실이나 요청한 결과를 정할 수 없으면 그 정보가 필요한 사례만 멈추고, 누락된 사실이나 결과를 확인한다.
- 비교를 이어가려면 요구사항이나 문서 작성 권한을 바꿔야 하는 경우 영향을 받는 비교를 멈추고 필요한 변경 내용을 확인한다.
- 실제 스킬 수정은 방안 선택과 수정 범위가 정해진 뒤 시작한다.
