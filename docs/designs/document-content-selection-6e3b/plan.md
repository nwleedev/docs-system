# 요청하지 않은 작업 설명을 제외하는 기준의 적용 계획

`use-better-terms`에 내용 선정 규칙을 반영하고 14개 입력으로 적용을 확인했다. 요청하지 않은 설명은 제외됐고 요청한 방법, 사실의 조건과 정확한 인용은 유지됐다. 필수 사실이 없는 입력과 검토만 요청한 입력도 각각 질문과 수정 제안으로 처리했다. 스킬 반영과 적용 확인을 마쳤다.

이 계획은 [요구사항의 내용이 포함되는 조건](./requirements.md#내용이-포함되는-조건), [조사할 해결 방안](./requirements.md#조사할-해결-방안), [계획에 담을 절차](./requirements.md#계획에-담을-절차)와 [확인할 결과](./requirements.md#확인할-결과)를 기준으로 한다. 내용 분류와 수록 지시 판정을 스킬에 반영하고, 기존 규칙을 조정한 뒤 실제 적용 문안을 확인한다. 구성 비교는 적용 방식과 반복 판정을 점검하는 근거로 사용한다.

## 1. 제외할 설명과 요청한 내용을 구분한다

[분류 기준](./references/content-classification.md)에 따라 [스킬의 내용 선정 단계](../../../skills/use-better-terms/SKILL.md#select-document-content)에 기본 제외 대상과 보존할 내용을 반영했다. 문장의 설명 대상과 요청한 내용을 기준으로 분류하며 단어만으로 삭제하지 않는다.

확인 근거는 각 유형의 포함 또는 제외 예시, 조건을 삭제했을 때 달라지는 주장, 실제 편집 안내와 검색 상황 사례의 연결이다. 같은 수행 절차라도 요청한 문서의 주제이면 유지하고 작성 활동의 회고이면 수록 지시를 확인한다. 2단계의 판정 절차는 이 분류를 사용한다.

## 2. 명시적 포함 지시를 판정하는 순서를 정한다

[판정 절차](./references/content-selection-procedure.md)를 [스킬의 세부 판정 자료](../../../skills/use-better-terms/references/document-content.md)에 반영했다. 수록 지시가 없으면 제외하고 지정된 문서와 내용만 허용한다. 예상 독자 지정은 필수 입력으로 요구하지 않는다.

확인 근거는 일반 보고서 요청과 방법 부록 요청의 구분, 동일한 뜻의 지시 두 표현, 지속적인 지시의 적용과 변경, 자료 속 인용의 제외 사례다. 본문에 필요한 사실이 부족한 경우만 문서 밖에서 확인한다. 이 순서와 포함 조건을 3단계의 기존 지침 대조에 사용했다.

## 3. 사실 보존과 기존 지침을 함께 적용한다

[기존 지침 대조](./references/guidance-alignment.md)에 따라 [스킬의 근거 수집](../../../skills/use-better-terms/SKILL.md#collect-evidence-and-run-checks)에서 독자 정보의 부재만으로 질문하거나 중단하지 않도록 고쳤다. 표현 판정과 질문은 검토 답변에 두고, 대상 본문에 넣으려면 그 문서에 대한 수록 지시를 확인한다.

확인 근거는 스킬에 반영한 내용 선정의 선행 조건, 근거가 부족할 때 질문할 대상과 보고 위치, 관찰 조건과 승인 상태를 보존하는 규칙이다. 기존 표현 검사와 판정 상태는 유지했다. 4단계의 적용 확인은 이 수정본을 사용했다.

## 4. 같은 입력으로 판정 차이를 비교한다

[14개 입력의 적용 확인](./references/skill-application-check.md)에 수정본의 실제 문안과 판정을 정리했다. 작성 요청, 사실 자료와 초안을 제공하고 기대 문안과 앞선 비교 결론은 제공하지 않은 별도 적용을 수행했다. [확장 전 12개 입력의 분석](./references/procedure-comparison.md)과는 구분했다.

확인 근거는 작성 문안 12개, 필수 사실 확인 질문과 검토만 하는 입력의 수정 제안이다. 제외 대상의 잔존, 필요한 내용과 조건의 삭제, 승인 추정과 독자 지정 질문은 발견되지 않았다. 검토 전용 원본은 적용 전후 내용이 같았고 평가용 인용은 정확히 보존됐다.

스킬 형식과 링크, 공백 검사는 통과했다. 이 확인은 한 번의 독립 적용 문안에 한정하며 실제 운영의 개선율을 뜻하지 않는다. 수록 판정 차이가 없어 스킬 규칙을 추가하지 않았다.

## 5. 두 스킬 구성 방안을 비교한다

[구성 방안 비교](./references/skill-composition-comparison.md)에 같은 문서 묶음의 수록 판정과 표현 검토를 마치는 조건을 적용했다. 논리적 호출은 확장안 한 번, 전용안 두 번이다. 활성화할 절차 본문도 각각 하나와 두 개이며 내용 판정 기준은 두 방안 모두 한 묶음으로 유지할 수 있다. 실제 토큰과 도구 실행 횟수는 측정하지 않았다.

확인 근거는 현재 저장과 공유 규칙, 두 방안의 호출 순서, 필요한 자료와 판정 근거 전달 조건이다. 자료 수집은 확장안에서 한 번이며 전용안에서도 전달하면 한 번으로 유지할 수 있다. 현재 확인한 지침은 저장 전 표현 검토를 요구하며, 내용 판정만 별도로 완료해야 하는 반복 작업은 확인되지 않았다.

현재 호출 규칙에 맞고 별도 근거 전달 절차가 필요하지 않은 확장안으로 스킬을 수정했다. 내용 선정과 표현 검토를 같은 단위로 수행했고 구성 자료도 실제 수정 상태에 맞춰 정리했다. 정확성 우열을 근거로 선택한 것은 아니며 독립 호출의 반복 필요가 확인되면 구성을 다시 비교한다.

## 후속 작업의 조건

이 계획의 범위는 문서 내용 선정 규칙의 스킬 반영과 적용 확인이다. 예상 독자를 지정하지 않았다는 이유로 중단하지 않는다.

- 본문에 필요한 사실이나 요청한 내용을 정할 수 없으면 그 정보가 필요한 사례만 멈추고, 누락된 사실이나 필수 내용을 확인한다.
- 비교를 이어가려면 요구사항이나 문서 작성 권한을 바꿔야 하는 경우 영향을 받는 비교를 멈추고 필요한 변경 내용을 확인한다.
- 기존 표현 검사를 약화하거나 문서 작성 권한을 바꿔야 하는 경우 그 변경이 필요한 작업을 멈추고 변경 조건을 확인한다.
