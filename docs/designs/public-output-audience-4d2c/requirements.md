# AI가 누구에게 작성하는지 구분하지 않는 문제

AI를 여러 애플리케이션 개발 프로젝트, 자료 수집 프로젝트에, 문제에 대한 리서치 프로젝트에 사용하면서 다음과 같은 문제가 발생했습니다.

AI(Codex, Claude Code 등)는 AI 본인이 작성하는 글이 "작업 지시자를 위한 글인지, 애플리케이션을 사용하는 사용자를 위한 글인지, 애플리케이션 개발에 참여하는 개발자를 위한 글인지" 구분하지 못한다. 즉 작업 지시자는 "사용자를 위한 글을 작성해라"라는 프롬프트를 입력해도 AI는 프롬프트를 그대로 받아들여서 작업 지시자를 위한 글을 작성하게 된다. 예를 들어 README.md 파일에 "이 파일을 사용자를 위한 글을 작성하라는 프롬프트에 대해서 작성한 글입니다."라는 내용이 작성된다.

그래서 사용자가 직접 사용해야 하에 웹 페이지 UI가 "마치 작업 지시자에게 어떻게 구현했는지 보고하는 듯한 문구"가 적혀있는 경우가 있다. 개발자들이 보는 README.md 파일에도 "작업 지시자에게 보고하는 듯한 문구"가 적히게 된다.

이 문제를 방지하기 위해서 사람들이 시도한 방법, 실제로 효과가 있었던 사례 등등, 위 문제를 대해서 리서치해주세요. 그리고 워크트리 브랜치를 생성해서 리서치 문서를 작성해주세요. 요구사항 문서는 빈 파일로 작성합니다.

작업을 할 때마다 README.md 파일을 참고하세요. **이 레포는 특정 서비스를 개발하는 프로젝트가 아닙니다.**

여러 프로젝트에서 재사용할 수 있는 **일종의 시스템**을 구축하는 프로젝트입니다.

- AI를 활용하여 프로젝트를 성공적으로 진행하는 방법을 파악
- AI를 활용하여 프로젝트의 진행 속도를 높이는 방법을 파악
- AI를 프로젝트에 활용할 때 발생하는 문제점을 찾아서 원인을 파악하고 해결 방안을 리서치

작업하는 동안 Git 커밋을 적절하게 관리하여 컨텍스트 압축에 대응하세요.
