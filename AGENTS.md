## Details

This repository is not intended for developing a conventional web service or application.

It is used to research how AI agents should carry out work.

1. How to document requirements and plans systematically and keep research materials coherently organized.
1. How to help AI agents write documents that enable task requesters to understand the subject correctly.
1. How to prevent AI agents from introducing antipatterns across the development scenarios that can arise in web service and application repositories.
1. How to optimize the token usage incurred when invoking skills and subagents.
1. How to track and analyze insights from widely used plugins.

This repository is not entirely code-free. For example, it may contain scripts designed and developed for AI agents to use alongside `SKILL.md` when invoking a skill. However, distributed skills must not depend on external packages.

The `skills` directory exists for research, not for distributing ready-to-use skills. Its purpose is to study how skills should be structured and to provide material that developers can customize for their own needs.

## Important

This repository is not intended for developing a conventional web service or application.

Do not infer or develop an application merely because it relates to a task requester's prompt.
